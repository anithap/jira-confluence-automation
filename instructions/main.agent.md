# Main Instructions

- For weekly status reports, follow [create-status-report.agent.md](create-status-report.agent.md) for input handling, fact-checking, and output requirements.
- For compound-interest calculations, follow [calculate-compound-interest.agent.md](calculate-compound-interest.agent.md) and run `tools/compound_interest.py` with the supplied inputs.
- For Jira JQL construction, follow [build-jql-query.agent.md](build-jql-query.agent.md); the tool builds but does not execute queries.
- For local Jira issue export checks, follow [validate-jira-issue-export.agent.md](validate-jira-issue-export.agent.md).
- For story-point field discovery, follow [use-discover_story_points_field.agent.md](use-discover_story_points_field.agent.md).
- For live active-sprint data verification, follow [use-verify_sprint_data.agent.md](use-verify_sprint_data.agent.md).
